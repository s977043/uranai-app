# MVP Scope

このドキュメントでは、AI占い師アプリの MVP 範囲を定義します。

## MVP Goal

最初のリリースでは、AI占い師を「未来を当てるプロダクト」ではなく、
**迷いを短時間で整理し、次の一歩を決めやすくする対話体験**として成立させる。

## Product Hypothesis

- ユーザーは高精度な予言より、感情整理と意思決定の後押しを求めている
- 恋愛・人間関係・今日の運勢は初期利用の入口になりやすい
- 1分で終わる軽い体験と、必要に応じた深掘り体験の両立が重要
- 匿名性と夜間即時利用は強い価値になる

## In Scope

### 1. デイリー占い
- 今日の結論
- 注意点
- 今日の一歩
- 一言メッセージ

### 2. テーマ別相談
- 恋愛
- 人間関係
- 仕事
- 今日の運勢

### 3. 会話型深掘り
- 初回回答のあとに追加質問で解像度を上げる
- 2〜3ターン程度の軽い対話を想定

### 4. 結果保存
- 直近の占い結果を閲覧できる
- 継続利用の文脈を持てる

### 5. 共有しやすい短文結果
- 1画面で完結する短文まとめ
- 将来的なSNS共有の土台にする

## Out of Scope

初期リリースでは以下を対象外とする。

- 本格的な出生図計算が必要な高度占星術
- 音声・ビデオ鑑定
- 人間占い師とのリアルタイム接続
- 大規模なコミュニティ機能
- 複雑な課金メニュー
- 高度な管理画面

## Theme Priority

優先順位:

1. 恋愛
2. 人間関係
3. 今日の運勢
4. 仕事

理由:
- 恋愛と人間関係は利用動機が強い
- 今日の運勢は日次リテンションを作りやすい
- 仕事相談は現実的な継続利用につながる

## UX Principles

- 最初の反応は速く、短く返す
- 結果は読みやすさ優先
- 神秘感は演出するが、過度に怪しくしない
- 結論だけで終わらず、必ず行動提案を含める
- 不安をあおらない

## Result Format

基本構造:

1. 結論
2. 今の流れ
3. 気持ちの解釈
4. 注意点
5. 今日の一歩
6. 一言メッセージ

## Success Metrics

MVPで見るべき指標:

- 初回利用後の再訪率
- 1セッションあたりの会話数
- デイリー占いの継続利用率
- 恋愛相談テーマの利用率
- 不適切応答率
- 通報率

## Release Readiness Checklist

- デイリー占いが成立している
- 恋愛 / 人間関係 / 仕事 / 今日の運勢の4テーマが揃っている
- 危険領域で安全応答に切り替わる
- AIによる占い体験であることを明示している
- 結果が1分以内で読める
- ログと改善観点が取得できる
