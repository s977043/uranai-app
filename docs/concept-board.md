# AI占い師 コンセプト・ボード

## コアコンセプト

迷いを、やさしく言語化する。

このサービスは、未来を断定する占いではなく、ユーザーの感情や迷いを整理し、次の一歩を決めやすくするための AI占い師 体験を提供する。

- 役割: 予言者ではなく、解釈者・伴走者
- 提供価値: 気分整理 / 背中押し / 匿名相談 / 毎日の小さな習慣
- ポジション: 占い × 対話 × セルフリフレクション

## 一言で表すと

恋愛・仕事・人間関係の迷いを、占い体験でやさしくほどくAI占い師アプリ

別案:

- 今日の気持ちを整える、対話型AI占い師
- 迷った夜に、そっと方向を照らすAI占い
- 当てるより、心を整えるAI占い師

## ターゲットユーザー

### メインターゲット

- 20〜39歳
- 恋愛・人間関係・仕事で小さな迷いを抱えやすい
- SNS/チャット文化に慣れている
- 占いに強い信仰はないが、気分整理の手段として使うことに抵抗がない

### サブターゲット

- 寝る前に不安が強くなりやすい人
- 誰にも言いにくい悩みを匿名で吐き出したい人
- 朝に短時間で今日の気分を整えたい人

## ユーザーインサイト

### 顕在ニーズ

- 今日どう動けばいいか知りたい
- 恋愛のモヤモヤを整理したい
- 誰かに話したいが、知人には話しにくい
- 長文相談は重いので、軽く話したい

### 潜在ニーズ

- 断定ではなく、安心したい
- 自分の気持ちをうまく言葉にしてほしい
- 決断の責任を丸投げせず、背中だけ押してほしい
- 毎日少しだけ、自分を整える儀式がほしい

## よく使われるシーン

### シーンA: 朝の1分

- これから仕事や学校に向かう前
- 今日の流れをざっくり把握したい
- 深い鑑定ではなく、短く前向きなメッセージがほしい

### シーンB: 返信を送る前

- 恋愛や人間関係で迷っている
- 送る / 待つ / 距離を置く、の判断を整理したい
- 自分の感情を言語化してから動きたい

### シーンC: 夜の不安時間

- 寝る前にモヤモヤが大きくなる
- 誰にも相談できず、考えがループする
- 気持ちを受け止めてもらい、明日の行動を1つ決めたい

### シーンD: 相性・話題作り

- 友人や恋人候補との相性を軽く見たい
- 会話のネタとして盛り上がりたい
- 共有しやすい短い結果がほしい

## 提供価値

### 機能価値

- 24時間すぐ相談できる
- 匿名で使える
- テーマ別に短時間で鑑定できる
- 日次利用しやすい

### 感情価値

- 気持ちが少し軽くなる
- 迷いが整理される
- 一人ではない感覚が得られる
- 次の一歩が見えやすくなる

### 社会的価値

- 人に見せづらい悩みでも相談しやすい
- 占いを自己理解の入口として使える

## 差別化ポイント

### 従来の占いアプリとの違い

- 「当たる」より「整う」を前面に出す
- 一方的な占い結果ではなく、対話で深掘りできる
- 悩みの種類に応じて、出力のトーンや深さを変えられる
- 行動アドバイスで終わるので、読後に次の一歩が残る

### 一般的な相談AIとの違い

- 占いらしい世界観と儀式感がある
- タロット / 数秘術 / 星座など、解釈のフレームがある
- 冷たいFAQではなく、感情に寄り添う読後感を作れる

## ブランド人格

### キャラクター像

- やさしい
- 落ち着いている
- 少し神秘的
- でも現実逃避させない
- 断定しすぎず、ユーザーの意思を尊重する

### 話し方

- 否定しない
- 先に安心感を出す
- 結論を短く、その後に解釈を添える
- 最後は必ず行動に落とす

### NG表現

- 絶対にこうなる
- この人は運命の相手だ
- いますぐ別れるべき
- 不幸になる
- 医療 / 法律 / 投資の断定助言

## ビジュアル方向性

### キーワード

- 夜
- 月
- 星
- ガラス
- 余白
- 静けさ
- やわらかな光
- 神秘感と可読性の両立

### UIトーン

- ダークベース
- 差し色に紫 / 紺 / 青緑 / 金のニュアンス
- 光りすぎず、落ち着いた高級感
- 装飾より読みやすさ優先

## 企画の要約

このAI占い師は、占いを「未来を断定するもの」ではなく、気持ちを整理し、次の一歩を見つけるための対話体験として再設計する。

主戦場は以下。

- 朝の1分
- 恋愛の迷い
- 夜の不安
- 匿名相談
- 相性ネタ

勝ち筋は、毎日使いたくなる軽さと、深い悩みにも入れる対話性の両立にある。
