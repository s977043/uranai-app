# Use Cases

AI占い師アプリの主要ユースケースを整理します。

## UC-01: 朝のデイリー占い

### Situation
- 出勤前、通学前、家事の合間などの短時間利用

### User Goal
- 今日の流れをざっくり把握したい
- 気持ちを整えて一日を始めたい

### Input
- テーマ: 今日の運勢
- 任意: 今の気分、気になる予定

### Expected Output
- 今日の結論
- 注意したいこと
- 今日の一歩
- 一言メッセージ

### Success Criteria
- 30秒〜1分で読める
- 読後に前向きな行動が1つ残る

## UC-02: 恋愛の返信前相談

### Situation
- 返信するか迷っている
- 相手の態度を深読みして不安になっている

### User Goal
- 今の感情を整理したい
- 送る / 待つ / 距離を置く の判断材料がほしい

### Input
- テーマ: 恋愛
- 相談文: 相手との状況
- 任意: 相手との関係性、直近の出来事

### Expected Output
- 今の流れの解釈
- 感情の整理
- 注意点
- 現実的な行動提案

### Success Criteria
- 断定しすぎない
- 不安をあおらない
- 読後に判断しやすくなる

## UC-03: 夜の不安整理

### Situation
- 寝る前に考えすぎてしまう
- 誰にも話せず感情がループする

### User Goal
- 気持ちを吐き出したい
- 明日に持ち越しすぎないよう整理したい

### Input
- テーマ: 不安 / 人間関係 / 恋愛 / 仕事
- 自由記述の悩み

### Expected Output
- 受容的な導入
- 今の感情の解釈
- 今日ここで止めてよいこと
- 明日やることを1つ

### Success Criteria
- 気持ちが少し軽くなる
- 行動が1つに絞られる
- 続けて依存的に再質問したくなりすぎない

## UC-04: 相性を会話ネタとして楽しむ

### Situation
- 友人や恋人候補との相性を軽く見たい
- シェアして話題にしたい

### User Goal
- 自己理解や会話ネタとして楽しみたい

### Input
- 自分と相手の基本情報
- テーマ: 相性

### Expected Output
- 関係性の特徴
- 良い相性ポイント
- 注意ポイント
- 共有しやすい短文まとめ

### Success Criteria
- 重すぎず楽しめる
- 共有しやすい
- ポジティブな会話のきっかけになる

## UC-05: 仕事の迷いを短く整理する

### Situation
- 優先順位、上司との関係、転職の迷いなど

### User Goal
- 頭の中を整理したい
- 今週やるべきことの方向性がほしい

### Input
- テーマ: 仕事
- 悩みの概要

### Expected Output
- 今の状態の整理
- 流れの解釈
- 注意点
- 次の一歩

### Success Criteria
- 抽象論だけで終わらない
- 現実的な行動に落ちる

## MVP Priority

優先度順:

1. UC-01 朝のデイリー占い
2. UC-02 恋愛の返信前相談
3. UC-03 夜の不安整理
4. UC-05 仕事の迷い整理
5. UC-04 相性ネタ

## Notes

- 初期体験は短く、深掘りは任意遷移にする
- すべてのユースケースで「結論 → 解釈 → 注意点 → 行動」の基本構造を保つ
- 医療・法律・投資・自傷関連は占い継続ではなく安全応答へ切り替える
