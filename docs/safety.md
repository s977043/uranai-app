# Safety Guidelines

AI占い師アプリの安全方針を整理します。

## Safety Principle

このプロダクトは、占いを通じて感情整理や自己理解を支援するものであり、
医療・法律・投資などの専門判断を代替するものではありません。

また、ユーザーの不安や依存を強める表現は避け、
読後に現実的な行動へ戻れる応答を重視します。

## Must Tell Users

UI や利用規約で少なくとも以下を明示する。

- これは AI による占い体験である
- 娯楽および自己理解の補助として提供している
- 医療・法律・投資の専門助言ではない

## Blocked / Restricted Topics

以下は占い応答を継続しない、または厳しく制限する。

### 1. 医療判断
- 病気の診断
- 治療方針の断定
- 薬の選択や中止の指示

### 2. 法律判断
- 違法性の断定
- 訴訟や契約判断の断定助言

### 3. 投資判断
- 特定銘柄の売買断定
- 利益保証
- 損失回避保証

### 4. 自傷・他害
- 自傷や自殺の示唆
- 他人を傷つける相談
- 危険行為の正当化

### 5. 依存をあおる表現
- 毎日必ず相談しないと危険
- この占いだけが正しい
- あなたは私なしではうまくいかない

## Response Policy

### Normal Response
- 共感を示す
- 断定しすぎない
- 流れや傾向として表現する
- 最後に小さな行動提案を付ける

### Safe Redirect Response
危険領域では以下の方針に切り替える。

- 占いの継続より安全を優先する
- 専門家や公的窓口への相談を促す
- 緊急時は地域の緊急連絡先や身近な支援先の利用を勧める
- 脅し・罪悪感・断定を使わない

## Tone Constraints

禁止または避けるべき表現:

- 絶対にこうなる
- 不幸になる
- 今すぐ別れないと終わる
- 病気に違いない
- 必ず儲かる

推奨表現:

- 今はこうした流れが見えます
- こういう傾向として受け取れます
- 無理のない範囲で、まずはこれを試してみてください
- ここは占いより専門家への相談が適しています

## Escalation Examples

### Case A: 自傷示唆
- 占いを続けない
- まず安全確保を促す
- 近くの信頼できる人、地域の緊急窓口、医療機関などへの相談を勧める

### Case B: DV / 虐待
- 相手を変える占いではなく安全確保を優先する
- 相談機関や支援窓口を案内する

### Case C: 医療不安
- 診断の代替をしない
- 体調不良がある場合は医療機関の受診を勧める

### Case D: 投資相談
- 相場予言や売買断定をしない
- 一般的な情報収集や専門家相談を促す

## Product Safeguards

- 連続利用に対する軽いクールダウン設計
- 危険ワード検知時の安全応答テンプレート
- テーマごとの出力制御
- 通報導線
- 監査用ログ

## Review Checklist

- 不安を過剰に増幅していないか
- 断定口調になっていないか
- 専門領域に踏み込みすぎていないか
- 依存を誘発していないか
- 読後に現実的な行動へ戻れるか
